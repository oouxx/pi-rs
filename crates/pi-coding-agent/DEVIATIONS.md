# DEVIATIONS.md — pi-coding-agent RPC Mode

This file documents intentional deviations from the TypeScript original
(`packages/coding-agent/src/modes/rpc/rpc-mode.ts`) in the Rust port.

| # | 位置 (ファイル:行/関数) | 原 TS 行为 | Rust 实际行为 | 修改原因 | 确认状态 |

| 1 | `handler.rs:Prompt` | TS emits `success(id, "prompt")` via `preflightResult` callback after preflight succeeds, or `error(id, "prompt", msg)` on failure. | Rust now emits `success(id, "prompt")` via the same preflight mechanism: `PromptOptions.preflight_result` is called with `true` when the prompt is accepted (queued or about to run) and `false` on preflight rejection; the RPC handler sends the success response on `true` and the error only if preflight never succeeded. | **Reversed**: `AgentSession::prompt()` now supports a `preflight_result` callback (matching TS `PromptOptions.preflightResult`), so the success response timing matches TS (prompt accepted, not run completed). | 已回退 (was 已确认保留) |

| 3 | `handler.rs:Fork` | TS returns `{text: string, cancelled: boolean}` where `text` is the selected text from the fork result. | Rust now returns `{text: <selected user-message text>, cancelled: false}` — the selected text is extracted from the forked entry via `session_manager.get_entry(entry_id)` (matching TS `extractUserMessageText`). | **Reversed**: the `text` field is now populated from the forked entry's user message content. | 已回退 (was 已确认保留) |
