# DEVIATIONS.md — pi-coding-agent RPC Mode

This file documents intentional deviations from the TypeScript original
(`packages/coding-agent/src/modes/rpc/rpc-mode.ts`) in the Rust port.

> **2026-10-26 审查后的清理**：已回退/已对齐的条目不再留在这里（行号
> #1 Prompt preflight、#2 NewSession rebind、#4 SwitchSession rebind、
> #5 GetCommands 来源、#7 prompt images/streamingBehavior、#8 bash
> excludeFromContext、#9 model_select 只发扩展、#12 ACP 初始模型、
> #17 extension_error、#31 grep/find spawn rg/fd 均已与 TS 一致；git
> 历史里有原文）。本文件现在只保留**仍然存在的**偏差与**未实现的缺口**；
> 编号不连续（#26 从未使用）。
>
> 同一轮修复（见 `PORTING_MISTAKES.md` #156–#162）：
> - `fork` 现在按 TS `position: "before"` 语义（分支不含被选中的那条用户
>   消息，文本回给客户端），`clone` 用 `position: "at"`；
> - `new_session` / `switch_session` / `fork` / 退出都会派发扩展的
>   `session_before_switch` / `session_before_fork` / `session_shutdown`；
> - RPC 的 `confirm` / `editor` 真正走 `extension_ui_request`（此前
>   `confirm` 硬编码 `false`、`editor` 不存在），`opts.timeout` 生效。
