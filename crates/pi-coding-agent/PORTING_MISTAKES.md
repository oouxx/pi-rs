# PORTING_MISTAKES.md — pi-coding-agent RPC Mode

This file documents bugs found and fixed during the RPC mode alignment check.

| # | 位置 | 现象 | 根因模式 | 修复方式 |

| 1 | `handler.rs:Prompt` | Prompt handler returned `None` — RPC client never got a response for prompt commands. | Missing success/error response emission. TS emits response via `preflightResult` callback; Rust had no equivalent. | Added success response emission in `AgentEnd` event listener. |
