# PORTING_MISTAKES.md — pi-tui

本文件归档 pi-tui 工具块渲染对齐检查中修复的回归 bug（翻译遗漏/实现错误，
非有意保留的偏差）。根因模式尽量归到阶段一"高危陷阱"表的分类。
